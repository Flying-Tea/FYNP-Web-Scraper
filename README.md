## Introduction

A scraper designed only to find volunteer listings and categorize listings by type, whether it's the type of job or age limits. This project is to serve as a start of a major overhaul from a previous prototype, Find Your Non-Profit previously created for the Alameda Hacks competition.

## Goal

Collect volunteer opportunities from multiple sources, format them and store in Supabase for future use.

- Link

- Skills Necessary
